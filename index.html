Trang Liên hệ: thay đổi và cách sửa trên site

Đối chiếu tab "Review tổng thể website" (dòng 70–72, kèm dòng 8, 22, 66 và Footer 18–25). Số đo lấy trên website-demo-02.thcmedia.vn/lien-he/ ngày 16/10/2026, màn hình 1440×900.

1 Bỏ nofollow (dòng 70, cùng gốc với dòng 4, 12, 18, 66)

HTML do template in ra không có nofollow. Nofollow được gắn lúc tải trang bởi file wp-content/themes/thcmedia-atlas/assets/js/core/external-links.js: file này gắn rel="nofollow" cho mọi link có href không chứa tên miền site, gồm cả tel:, mailto:, Zalo, Facebook, YouTube và link #. Trang Liên hệ hiện có 51 link bị gắn (19 tel, 2 mailto, 23 link ngoài, 5 link #, 2 link nội bộ). Google đọc trang sau khi chạy JS nên vẫn thấy nofollow.

  • Cách sửa: gỡ enqueue file external-links.js. Sửa template không có tác dụng vì script chạy sau.
  • Cần nofollow cho link ngoài trong bài viết thì gắn tay trong trình soạn thảo, đừng gắn hàng loạt.
  • Kiểm: mở trang → DevTools → tab Elements → Ctrl+F gõ nofollow → 0 kết quả ở header, khối liên hệ, tư vấn viên, footer.
